# Erling Haaland Performance Analysis Dashboard ⚽📊

A modern football analytics dashboard built using **Power BI** to analyze Erling Haaland's 2025/26 Premier League season performance with interactive visuals, player insights, and advanced statistics.

## 🚀 Features

* Interactive KPI cards for Goals, Assists, xG, Rating, Shots, Matches Played, and Duels Won
* Shooting Overview using Column Charts
* Passing Statistics using Horizontal Bar Charts
* Goal Breakdown visualization using Donut Chart
* Shot Accuracy Gauge Chart
* Player Attribute Radar Chart
* Goals Over Time Line Chart
* Manchester City themed UI design with modern football analytics styling
* Custom player image, club logo, and dark neon dashboard theme

## 🛠️ Technologies Used

* Power BI
* Excel Dataset
* DAX Measures
* Custom Visualizations

## 📈 Key Dashboard Insights

* 27 Goals scored in Premier League 2025/26
* 25.43 Expected Goals (xG)
* 59 Shots on Target
* 47% Shot Accuracy
* 130 Duels Won
* 7.68 Average Rating
